# GUI for Google Lyria

Graphic user interface for generating and editing audio with Google Lyria

![](https://shields.io/badge/dependencies-Python_3.14-blue)
![](https://shields.io/badge/dependencies-aistudio.google.com-blue)

## Acknowledgement

[librosa](https://github.com/librosa/librosa) (modified)

[Lyric synchronization](https://github.com/cloudy-sfu/Lyric-synchronization) (require web browser)



## Install

Create and activate a Python virtual environment.

Run the following command in terminal.

```
pip install -r requirements.txt
```



## Usage

Run the following command in terminal.

```
python main.py
```
